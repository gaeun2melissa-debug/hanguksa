# 한국사 지도

수능·한능검 공부용 한국사 지도 앱. 사이트: https://meao-moare.github.io/hanguksa/

- `index.html` — 사이트에 올라가는 완성본 (직접 고치지 말고 `src/`를 고친 뒤 빌드)
- `src/` — 앱의 조각 파일들 (`a_head.html` = 화면·스타일, `*.js` = 기능·데이터, `fb_module.html` = 구글 로그인·동기화)
- `src/build.sh` — `bash src/build.sh` 하면 `index.html`과 `src/app.html`(클로드 아티팩트용)을 다시 만든다
